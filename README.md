# Drum 🥁 Kit

버튼을 클릭하거나 키보드를 눌러 드럼 소리를 연주하는 웹 프로젝트입니다. HTML, CSS, JavaScript로 화면을 구성하고, 클릭·키보드 이벤트에 따라 소리와 시각 효과를 연결하는 방법을 연습할 수 있습니다.

## 주요 기능

- **드럼 버튼 7개**: 탐 드럼 4개, 스네어, 크래시 심벌, 베이스 드럼을 연주합니다.
- **마우스·키보드 조작**: 화면의 버튼을 클릭하거나 해당 영문 소문자 키를 누르면 소리가 재생됩니다.
- **눌림 효과**: 연주한 버튼에 그림자와 반투명 효과가 약 0.2초 동안 적용됩니다.
- **클릭 시 글자색 변경**: 마우스로 클릭한 버튼의 글자가 흰색으로 바뀝니다. 현재 코드에서는 원래 색으로 돌아오지 않습니다.
- **악기 이미지**: 각 버튼에 해당 악기 이미지를 배경으로 표시합니다. 이미지 파일을 별도로 준비해야 합니다.

## 키 매핑

키보드를 영문 입력 상태로 전환한 뒤 아래 소문자 키를 눌러 주세요. 화면의 같은 글자 버튼을 클릭해도 연주할 수 있습니다.

| 키 | 악기 | 이미지 파일 | 소리 파일 |
| --- | --- | --- | --- |
| `w` | 탐 드럼 1 | `images/tom1.png` | `sounds/tom-1.mp3` |
| `a` | 탐 드럼 2 | `images/tom2.png` | `sounds/tom-2.mp3` |
| `s` | 탐 드럼 3 | `images/tom3.png` | `sounds/tom-3.mp3` |
| `d` | 탐 드럼 4 | `images/tom4.png` | `sounds/tom-4.mp3` |
| `j` | 스네어 드럼 | `images/snare.png` | `sounds/snare.mp3` |
| `k` | 크래시 심벌 | `images/crash.png` | `sounds/crash.mp3` |
| `l` | 베이스 드럼 | `images/kick.png` | `sounds/kick-bass.mp3` |

> 현재 코드는 `event.key` 값을 그대로 비교합니다. Shift 또는 Caps Lock으로 입력한 대문자는 소리 재생 키와 일치하지 않습니다.

## 실행 방법

### 1. 프로젝트 파일 준비하기

GitHub 저장소에서 **Code → Download ZIP**을 선택하고 압축을 풀거나, 저장소를 컴퓨터에 복제합니다. `index.html`, `styles.css`, `app.js`는 같은 폴더에 둡니다.

### 2. 이미지와 소리 파일 추가하기

제공된 소스 파일은 `index.html`, `styles.css`, `app.js`입니다. **`images/`와 `sounds/` 폴더 및 그 안의 자산 파일은 제공되지 않았으므로 별도로 준비해야 합니다.**

프로젝트 폴더 안에 두 폴더를 만들고, 위 키 매핑 표에 적힌 이름으로 파일을 넣어 주세요. 파일 이름과 확장자, 대소문자까지 코드의 경로와 일치해야 합니다. 자산을 준비할 때는 사용·배포가 허용된 자료인지 확인해 주세요.

### 3. 브라우저에서 열기

`index.html`을 더블 클릭해 웹 브라우저에서 엽니다. 별도의 패키지 설치나 빌드 과정은 없습니다.

개발 중에는 VS Code의 **Live Server** 같은 로컬 서버 도구를 사용해도 됩니다. 파일을 수정한 후 브라우저를 새로고침해 결과를 확인하세요.

### 4. 연주하기

드럼 버튼을 클릭하거나 `w`, `a`, `s`, `d`, `j`, `k`, `l` 키를 누릅니다. 키보드 조작 시에는 웹페이지를 한 번 클릭해 페이지에 입력 초점을 맞춰 주세요.

## 파일 구조

아래 구조에서 `images/`와 `sounds/` 및 그 안의 파일은 **별도로 추가해야 하는 필수 자산**입니다.

```text
drum-kit/
├── index.html          # 제목, 드럼 버튼, CSS·JavaScript 연결
├── styles.css          # 화면 스타일, 악기 배경 이미지, 눌림 효과
├── app.js              # 클릭·키보드 이벤트, 소리 재생, 효과 처리
├── README.md           # 프로젝트 안내 문서
├── images/             # 별도 준비 필요: 버튼 배경 이미지
│   ├── tom1.png
│   ├── tom2.png
│   ├── tom3.png
│   ├── tom4.png
│   ├── snare.png
│   ├── crash.png
│   └── kick.png
└── sounds/             # 별도 준비 필요: 드럼 음원
    ├── tom-1.mp3
    ├── tom-2.mp3
    ├── tom-3.mp3
    ├── tom-4.mp3
    ├── snare.mp3
    ├── crash.mp3
    └── kick-bass.mp3
```

## 기술 스택

| 기술 | 역할 |
| --- | --- |
| HTML5 | 제목, 버튼, 푸터 등 페이지 구조 작성 |
| CSS3 | 색상, 글꼴, 버튼 배경 및 눌림 효과 구현 |
| JavaScript | DOM 요소 선택 및 클릭·키보드 이벤트 처리 |
| 브라우저 `Audio` API | MP3 음원 재생 |
| Google Fonts의 Arvo | 제목과 버튼의 글꼴 표시 |

별도의 JavaScript 프레임워크나 외부 JavaScript 라이브러리는 사용하지 않습니다.

## 코드 살펴보기

- `handclick(event)`: 클릭한 버튼의 글자색을 바꾸고, 버튼 글자에 해당하는 소리와 효과를 실행합니다.
- `handlekey(event)`: 누른 키를 읽어 소리와 효과를 실행합니다.
- `soundDrum(text)`: 키에 맞는 음원으로 `Audio` 객체를 만들고 재생합니다.
- `animationDrum(text)`: 해당 버튼에 `.pressed` 클래스를 추가하고, 200밀리초 후 제거합니다.

## 참고사항

- **불필요한 닫는 태그**: 제공된 `index.html`에는 `<script src="app.js"></script>` 다음 줄에 `</script>`가 한 번 더 있습니다. 추가된 닫는 태그는 삭제해 아래처럼 정리하면 됩니다.

  ```html
  <script src="app.js"></script>
  </body>
  </html>
  ```

- **문서 언어**: HTML의 `lang="kr"`은 한국어 언어 코드인 `lang="ko"`로 수정하는 것이 좋습니다.
- **이미지가 보이지 않을 때**: `images/` 폴더의 위치와 파일 이름을 확인하세요. 이미지가 없어도 버튼은 표시되지만 악기 배경은 나오지 않습니다.
- **소리가 나지 않을 때**: `sounds/` 폴더의 위치와 파일 이름, 컴퓨터 음량, 브라우저 탭 음소거 여부를 확인하세요. 현재 코드에는 음원 로딩·재생 실패 안내가 없습니다.
- **인터넷 연결**: Arvo 글꼴은 Google Fonts에서 불러옵니다. 인터넷 연결이 없거나 요청이 차단되면 대체 글꼴로 표시될 수 있습니다.
- **키 입력 처리 개선**: `animationDrum()`은 입력값을 CSS 선택자에 직접 연결합니다. 일부 특수문자 키는 선택자 오류를 일으킬 수 있으므로, 개선할 때는 허용된 7개 키인지 먼저 확인하는 것이 좋습니다.
- **미사용 스타일**: `.game-over`와 `.red`는 CSS에 정의되어 있지만, 제공된 HTML과 JavaScript에서는 사용하지 않습니다.

이 문서는 제공된 세 소스 파일을 확인해 작성했습니다. 이미지와 음원이 제공되지 않아 실제 자산을 포함한 소리 재생과 화면은 검증하지 않았습니다.
